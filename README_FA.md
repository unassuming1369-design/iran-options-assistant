# دستیار اختیار معاملات ایران — نسخه ۵.۱

نسخه ۵.۱ توسعه نسخه ۴.۲ است و فایل‌های اصلی تحلیل بازار و موتور تصمیم‌گیری قبلی را حفظ می‌کند. این پروژه برای Node.js 18+، تلگرام و Render طراحی شده است.

## امکانات

- دریافت زنجیره اختیار از TSETMC و مسیرهای جایگزین قبلی؛ تحلیل تکنیکال سهم پایه، نقدشوندگی، دفتر سفارش، جریان حقیقی/حقوقی، PCR، موقعیت باز و استراتژی‌های محدودریسک.
- موتور تصمیم‌گیری مرکزی با کنترل تازگی داده، ساعت معمول بازار، نقدشوندگی، نسبت حداقل سود به زیان ۱:۲ و بودجه مستقل هر ورود ۶۰٪ سرمایه (۳ میلیون تومان در سرمایه ۵ میلیون)، حد زیان برنامه‌ریزی‌شده ۲۰٪ بهای تمام‌شده و حداقل نسبت سود به زیان ۱:۲. در داده ناقص «عدم معامله».
- جست‌وجوی اطلاعیه‌های کدال با Search API مورد استفاده وب‌سایت کدال (`search.codal.ir/api/search/v2/q`). این API مستند رسمی عمومی پایدار ندارد و ممکن است ساختار/دسترسی آن تغییر کند؛ خطا به‌صورت صریح گزارش می‌شود.
- گردآوری خبر از RSS خبرگزاری‌های ایرنا، ایسنا، تسنیم، مهر و دنیای اقتصاد؛ منابع ناموفق در گزارش مشخص می‌شوند. RSS یا اتصال شبکه ممکن است در Render در دسترس نباشد.
- ثبت و مدیریت موقعیت‌های خرید و فروش Call و Put، با شناسه مستقل، قیمت ورود، تعداد، اندازه قرارداد و سررسید؛ بررسی دستی، قیمت خروج قابل مشاهده و جهت تکنیکال سهم پایه را کنار هم نشان می‌دهد.
- بررسی دستی موقعیت و پایش خودکار هر ۵ دقیقه (قابل تنظیم)؛ هشدار در تغییر قابل‌توجه سود/زیان. آستانه هشدار زیان ۲۰٪ و هدف سود اولیه ۱۰٪ نسبت به بهای تمام‌شده است؛ تکرار هشدار برای هر موقعیت با فاصله زمانی محدود می‌شود.
- پیشنهاد وضعیت و قیمت خروج بر اساس سمت قابل معامله دفتر سفارش: برای موقعیت Long قیمت تقاضا (Bid)، برای Short قیمت عرضه (Ask). در نبود داده زنده/قابل معامله، قیمت یا سیگنال ساخته نمی‌شود.
- هیچ سفارش واقعی ثبت، اصلاح یا لغو نمی‌شود؛ تأیید انسانی برای هر اقدام بیرون از ربات ضروری است.

## دستورات تلگرام

- `/start` یا `/help` — راهنما
- `/market` — نمای کلی زنجیره اختیار
- `/scan` — نمادهای دارای بیشترین ارزش معاملات اختیار
- `/analyze فولاد` — تحلیل چندبخشی نماد پایه و ترکیب اخبار/کدال در صورت دسترسی
- `/signal فولاد` — تصمیم مرکزی و سیگنال مشروط
- `/strategy فولاد` — رتبه‌بندی استراتژی‌های محدودریسک
- `/chain فولاد` — فهرست قراردادهای اختیار نماد
- `/news فولاد` — پیام‌های ناظر TSETMC
- `/research فولاد` — جست‌وجوی کدال و خبرگزاری‌ها
- `/position list` — فهرست موقعیت‌های باز
- `/position add فولاد نمادقرارداد call long 10000 1405/12/20 850 5` — ثبت موقعیت (نماد پایه، نماد دقیق قرارداد، نوع call/put، سمت long/short، قیمت اعمال، سررسید، قیمت ورود به تومان، تعداد). اندازه قرارداد از زنجیره TSETMC گرفته می‌شود.
- `/position check` یا `/position check P...` — بررسی دستی همه موقعیت‌ها یا یک موقعیت
- `/position close P...` — بستن پرونده در ربات؛ این فرمان سفارش بورسی نمی‌فرستد.
- `/risk`، `/status`، `/debug` — ریسک، وضعیت و عیب‌یابی

## تنظیمات Render

متغیرهای فعلی را نگه دار: `TELEGRAM_BOT_TOKEN` و `WEBHOOK_SECRET`.

اختیاری:
- `CAPITAL_TOMAN=5000000`
- `RISK_PER_TRADE_PCT=0.005`
- `MAX_RISK_PCT=0.01`
- `MIN_RR=2`
- `POSITION_MONITOR_INTERVAL_MS=300000`
- `POSITION_DATA_DIR=/var/data`

### ماندگاری موقعیت‌ها

برای اینکه پرونده‌های ثبت‌شده پس از Deploy/Restart پاک نشوند، در Render برای سرویس Web یک Persistent Disk با Mount Path برابر `/var/data` بساز و متغیر `POSITION_DATA_DIR=/var/data` را تنظیم کن. بدون دیسک پایدار، فایل JSON ممکن است در Deploy یا Restart از بین برود. پایش خودکار نیز فقط وقتی سرویس Render روشن است اجرا می‌شود؛ این سیستم تضمین پایش ۲۴ساعته خارج از ساعت/دسترسی سرویس نمی‌دهد.

## نصب

۱. از مخزن فعلی یک ZIP پشتیبان بگیر.
۲. ZIP این نسخه را استخراج کن.
۳. در ریشه مخزن GitHub فایل‌های زیر را جایگزین/اضافه کن: `index.js`، `core.js`، `decision-center.js`، `package.json`، `README_FA.md`، `INSTALL_FA.txt`، `position-manager.js`، `research-sources.js` و پوشه `tests/`.
۴. فایل‌های هم‌نام را جایگزین کن؛ فایل‌های دیگر مخزن را حذف نکن.
۵. Commit changes را بزن و Deploy Render را بررسی کن.
۶. پس از Deploy به‌ترتیب `/status`، `/market`، `/research فولاد`، `/position list` و `/analyze فولاد` را تست کن.

## تنظیمات سرمایه و کنترل ریسک\n\n- سرمایه مبنا: ۵٬۰۰۰٬۰۰۰ تومان. بودجه هر ورود مستقل: ۶۰٪ سرمایه = ۳٬۰۰۰٬۰۰۰ تومان. این سقف برای هر ورود است، نه سقف مجموع همه موقعیت‌ها.\n- حد زیان برنامه‌ریزی‌شده در خرید تکی: ۲۰٪ بهای تمام‌شده؛ در ورود کامل ۳ میلیون تومانی برابر ۶۰۰ هزار تومان. این حد تضمین اجرای خروج نیست و زیان نهایی اختیار خرید تا کل پرمیوم پرداختی ممکن است برسد.\n- هدف اولیه سود: بیش از ۱۰٪. برای حفظ R:R حداقل ۱:۲، هدف سناریویی باید دست‌کم دو برابر زیان برنامه‌ریزی‌شده باشد؛ با حد ۲۰٪، هدف متناظر ۴۰٪ است.\n- بودجه هر ورود مستقل است؛ مجموع تعهدات چند موقعیت باز جداگانه باید توسط کاربر پایش شود.\n\n## محدودیت‌ها و کنترل ریسک

- اتصال کدال و خبرگزاری‌ها از API جست‌وجوی وب‌سایت/RSS عمومی استفاده می‌کند؛ API رسمی و تضمین‌شده نیست. در صورت خطای منبع، خبر/اطلاعیه جایگزین ساخته نمی‌شود.
- خبرخوان RSS به معنی تأیید صحت خبر یا تحلیل معنایی کامل نیست. زمان، متن اصلی، منبع و ارتباط خبر با نماد باید بررسی شوند.
- موقعیت فروش اختیار می‌تواند زیان بالقوه بسیار بزرگ یا نامحدود داشته باشد. برای Short، مقدار سود/زیان باز صرفاً برآورد لحظه‌ای بر مبنای Ask است و جایگزین محاسبه وجه تضمین/ریسک پرتفوی نیست. قراردادهای بدون پوشش را با ریسک نامحدود تلقی کن.
- تحلیل مدیریت پوزیشن در این نسخه برای هر قرارداد تکی انجام می‌شود. برای اسپردها/استراتژی‌های چندپایه باید هر پایه جداگانه ثبت شود؛ محاسبه یکپارچه P/L و ریسک پرتفوی چندپایه هنوز کامل نیست.\n- پیشنهاد میانگین کم‌کردن خودکار وجود ندارد. خرید مجدد فقط پس از تحلیل مستقل و بررسی ریسک مجاز است؛ این نسخه برای افزایش پوزیشن، قیمت هدف حدسی نمی‌سازد.
- قیمت فعلی قرارداد از آخرین داده دریافتی زنجیره گرفته می‌شود. خروج Long با Bid و بستن Short با Ask سنجیده می‌شود؛ اگر این سمت دفتر سفارش موجود نباشد، خروجی عملیاتی صادر نمی‌شود.
- P/L محاسبه‌شده کارمزد، مالیات، لغزش، صف، وجه تضمین، سود/زیان سایر اجزای پرتفوی و محدودیت‌های کارگزاری را شامل نمی‌شود.
- هشدارهای خودکار در هر ۵ دقیقه اجرا می‌شوند، اما به uptime سرویس و دسترسی TSETMC وابسته‌اند. این ربات سفارش ثبت نمی‌کند.
- بنیادی کامل از روی صورت‌های مالی PDF/XBRL در این نسخه پیاده نشده؛ جست‌وجوی اطلاعیه‌ها و لینک اصل گزارش از کدال انجام می‌شود.
- ساعت بازار، بازه معمول را می‌سنجد و تقویم تعطیلات رسمی/تعطیلی موردی متصل نیست.
