# دستیار اختیار معاملات ایران — نسخه ۴.۲

این نسخه برای اجرای Node.js روی Render و دریافت پیام تلگرام طراحی شده است. خروجی‌های عادی ربات فارسی ساده‌اند و نام فیلدهای برنامه‌نویسی را به کاربر نشان نمی‌دهند؛ فقط دستور `/debug` برای عیب‌یابی فنی است.

## چه موتورهایی دارد؟

- دریافت داده از API زنجیره اختیارِ پشت سایت `tsetmc.ir` به‌عنوان منبع اصلی؛ تبدیل ردیف‌های جفت‌شده Call و Put به قراردادهای استاندارد.
- در صورت خطا یا تغییر ساختار API اصلی، استفاده از دو مسیر جایگزین نمای بازار اختیار در `webgw.tse.ir`؛ دسترسی این درگاه ممکن است بر اساس IP سرور محدود باشد، بنابراین مسیر جایگزین تضمین‌شده نیست.
- تطبیق هر قرارداد با دارایی پایه، قیمت اعمال، اندازه قرارداد و سررسید.
- نمایش آخرین قیمت، قیمت پایانی، عرضه و تقاضا، حجم، ارزش معاملات و موقعیت باز؛ هر فیلدی که در پاسخ منبع نباشد «نامشخص» نمایش داده می‌شود.
- تحلیل تکنیکال سهم پایه: EMA 9/21، RSI 14، MACD، حمایت و مقاومت تقریبی ۲۰/۶۰ روزه و حجم نسبی.
- بررسی جریان خرید و فروش حقیقی/حقوقی در صورت برگشت داده معتبر.
- دریافت پیام‌های ناظر و تلاش برای دریافت فهرست اطلاعیه‌های کدال از مسیر عمومی TSETMC.
- رتبه‌بندی نقدشوندگی قراردادها و محاسبه فاصله قیمت عرضه و تقاضا.
- ارزیابی خرید Call/Put و اسپردهای بدهکار صعودی/نزولی با سناریوی سررسید و کنترل ریسک.
- محاسبه IV و یونانی‌ها فقط اگر `RISK_FREE_RATE` معتبر و دستی در Render تنظیم شده باشد؛ خروجی بر اساس فرض مدل اروپایی تقریبی است.
- گزارش عدم معامله در نبود داده کافی یا نبود نسبت سود به زیان حداقل ۱ به ۲.

## محدودیت‌هایی که عمداً پنهان نشده‌اند

1. این ربات سفارش ثبت نمی‌کند و به حساب کارگزاری متصل نیست.
2. API زنجیره اختیار پشت `tsetmc.ir` ممکن است گاهی خالی، کند، مسدود یا با تأخیر باشد. درگاه جایگزین `webgw.tse.ir` نیز در برخی سرورها به‌دلیل IP محدود ممکن است در دسترس نباشد. زمان دریافت ربات، زمان قطعی آخرین معامله نیست؛ همیشه زمان آخرین معامله منبع را جداگانه کنترل کن.
3. کیفیت تحلیل تکنیکال به وجود حداقل ۳۵ رکورد روزانه معتبر وابسته است.
4. ورود پول حقیقی/حقوقی فقط از حجم‌های قابل دریافت گزارش می‌شود و به معنی شناسایی هویت معامله‌گر یا «ورود پول هوشمند» نیست.
5. تغییر موقعیت باز فقط در صورت دسترسی به مقدار فعلی و مقدار روز قبل قابل مقایسه است؛ تاریخچه محلی ممکن است با ری‌استارت یا Deploy سرویس رایگان Render پاک شود.
6. داده‌های بنیادی محدود به فیلدهایی است که TSETMC در اطلاعات نماد بازمی‌گرداند و استخراج کامل صورت‌های مالی از XML/HTML کدال در این نسخه ادعا نمی‌شود.
7. سود و زیان سناریوهای اختیار، کارمزد، مالیات، لغزش قیمت، ارزش زمانی باقیمانده و تغییر IV را تضمین نمی‌کند.
8. برای یونانی‌ها و IV، نرخ بدون ریسک از پیش حدس زده نشده است؛ باید مقدار معتبر را خودت از منبع رسمی/قابل‌اتکا تهیه کنی.

## نصب روی مخزن GitHub موجود

1. ZIP را باز کن.
2. در مخزن `iran-options-assistant` فایل‌های `index.js`، `core.js` و `package.json` را با فایل‌های همین بسته جایگزین کن. پوشه `tests` و `README_FA.md` را هم بارگذاری کن.
3. در GitHub روی Commit changes بزن.
4. Render باید به‌صورت خودکار Deploy کند؛ اگر نکرد، از صفحه سرویس Manual Deploy را اجرا کن.
5. متغیرهای محیطی فعلی `TELEGRAM_BOT_TOKEN` و `WEBHOOK_SECRET` را نگه دار. لازم نیست توکن را دوباره بسازی یا در کد قرار دهی.
6. تنظیمات ریسک اختیاری‌اند و پیش‌فرضشان همان ۵ میلیون تومان، ریسک هدف ۰٫۵٪، سقف ۱٪ و نسبت حداقل ۱:۲ است.

## دستورات تلگرام

- `/analyze فولاد` — گزارش چندبخشی نماد پایه
- `/signal فولاد` — تصمیم مرکزی و سیگنال مشروط با کنترل سخت‌گیرانه
- `/strategy فولاد` — رتبه‌بندی استراتژی‌های محدودریسک
- `/chain فولاد` — فهرست قراردادهای اختیار نماد
- `/news فولاد` — پیام‌های ناظر نماد
- `/risk` — سرمایه و حدود ریسک
- `/status` — وضعیت ربات
- `/debug` — گزارش فنی برای عیب‌یابی

## وب‌هوک تلگرام

مسیر وب‌هوک `/telegram` است. چون متغیر `WEBHOOK_SECRET` از قبل در Render تنظیم شده، وب‌هوک موجود را نگه دار؛ فقط در صورتی آن را دوباره تنظیم کن که مقدار Secret را عوض کرده باشی.

## نمونه خروجی عادی

ربات به‌جای کدهای API می‌نویسد: «قیمت سهم پایه»، «روند صعودی/نزولی»، «فاصله عرضه و تقاضا»، «حجم معاملات»، «ریسک این معامله» و «عدم معامله». دستور `/debug` تنها استثناست.

## سایت مرجع کاربر

صفحه‌ای که برای نمای بازار اختیار مبنا قرار گرفته است: `https://tsetmc.ir/#`

## اولویت منابع داده

1. منبع اصلی زنجیره اختیار: `cdn.tsetmc.com/api/Instrument/GetInstrumentOptionMarketWatch/1`؛ این همان مسیر داده‌ای است که کد از طریق آن اطلاعات نمای اختیار سایت `tsetmc.ir` را می‌خواند.
2. در صورت خطا یا تغییر ساختار منبع اصلی، ربات تلاش می‌کند از `webgw.tse.ir/InstrumentProvider/api/v1/MarketWatch/MarketWatchTradeOption/fa` و سپس `MarketWatchOption/fa` استفاده کند.
3. درگاه `webgw.tse.ir` ممکن است از بعضی IPهای میزبانی خارج از ایران پاسخ ندهد؛ به همین دلیل منبع اصلی همچنان API پشت `tsetmc.ir` باقی مانده است.

جزئیات مسیرهای جایگزین و شکل جفت‌شده‌ی Call/Put بر پایه نقشه فنی منتشرشده از APIهای TSE پیاده‌سازی شده است. تعداد آیتم‌ها در بازار ثابت نیست و نباید به تعداد نمونه‌های مستندشده وابسته بود.


## موتور تصمیم‌گیری مرکزی نسخه ۴.۲

ماژول `decision-center.js` تصمیم نهایی را با کنترل زمان داده، ساعت بازار تهران، جهت تکنیکال، وجود داده بنیادی، نقدشوندگی واقعی، نسبت سود به زیان حداقل ۱:۲ و بودجه ریسک می‌گیرد. در صورت نقص داده یا بسته بودن بازار، نتیجه «عدم معامله» است. امتیاز ۰ تا ۱۰۰ امتیاز کیفی شواهد است و احتمال موفقیت آماری نیست.

**محدودیت مهم:** در نسخه فعلی، بنیادی از فیلدهای پایه TSETMC و اخبار از پیام ناظر/خروجی عمومی کدال استخراج می‌شود؛ خبرخوان جامع اقتصاد و سیاست، احساسات شبکه‌های اجتماعی، تشخیص هویت نهنگ‌ها، سفارش‌گذاری و تأیید اجرای معامله وجود ندارد. تغییر OI تنها با مقایسه snapshotهای ذخیره‌شده قابل مشاهده است و به‌تنهایی اثبات ورود پول هوشمند نیست. قیمت‌های TSETMC در محاسبات قدیمی موتور به‌صورت ریال فرض و برای نمایش/ریسک به تومان تبدیل می‌شوند؛ واحد و قیمت نهایی را در کارگزاری کنترل کن.

**کنترل بازار:** ورود جدید فقط در روزهای یکشنبه تا پنجشنبه و بازه معمول ۰۹:۰۰ تا ۱۲:۳۰ تهران مجاز شمرده می‌شود. تعطیلات رسمی/تعطیلی موردی از تقویم رسمی به‌صورت خودکار متصل نیست؛ در روزهای تعطیل رسمی حتی اگر ساعت بازه باشد، خودت وضعیت بازار را بررسی کن. هیچ سفارش خودکاری ثبت نمی‌شود.
